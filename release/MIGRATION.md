# Moving to Aurora Universal

Aurora Universal has its own Firefox Add-ons listing and extension ID, `aurora-universal@pigeonlabs`.

Aurora for ChatGPT LibreWolf uses `aurora-for-chatgpt-librewolf@local`. Universal installs separately, so preferences need to be imported.

## Keep your preferences

1. Open the old extension's settings and choose **Export Settings**.
2. Install Aurora Universal and open its settings.
3. Choose **Import Settings**, paste the exported JSON, and import it.
4. Select any uploaded background image or video again in Universal.
5. Disable the old extension in Firefox's add-on manager so both extensions do not style the same page.

The old extension retains its stored data while disabled. Exported preferences do not include uploaded background files, which are stored separately in the browser.
