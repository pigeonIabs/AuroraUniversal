# Aurora Universal 1.0.0

Aurora grows beyond ChatGPT. The first Universal release brings glass, backgrounds, and shared preferences to ChatGPT, Claude, Gemini, Grok, Qwen, Google AI Studio, DeepSeek, and Hugging Face.

## A familiar interface with a different atmosphere

Adjust glass transparency, switch between light and dark themes, and choose an image or video background. Each website keeps its own layout, shapes, and controls. Reading fonts are bundled with the extension.

## Controls that follow the page

Quick settings and toolbar preferences show the options supported by the current site. Focus mode, cinema width, history blur, and sensitive text masking are available alongside message queues and native model preferences where supported.

Promotions, usage notices, and AI disclaimers have separate controls. ChatGPT sponsored-placement hiding is enabled by default. This hides page elements rather than blocking ad network requests.

## Moving from an earlier build

Universal begins at `1.0.0`. Earlier development builds used `1.8.*` while the project was transitioning from Aurora for ChatGPT.

Universal has its own extension ID and installs separately from Aurora for ChatGPT LibreWolf. Export preferences from the old settings panel and import them into Universal, then disable the old extension. Select uploaded background files again in Universal. [Migration details](MIGRATION.md).

Preferences use browser storage and can follow Firefox Sync. Uploaded backgrounds stay local. [Privacy details](../PRIVACY.md).
