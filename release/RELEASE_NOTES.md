# Aurora Universal 1.0.0

Universal expands [Aurora for ChatGPT](https://github.com/TG-TG-TG-TG-TG-TG/Aurora-for-ChatGPT) to seven more websites.

- Added support for Claude, Gemini, Grok, Qwen, Google AI Studio, DeepSeek, and Hugging Face.
- Added an animated Space theme with a rotating starfield, twinkling stars, and shooting stars.
- Significantly improved performance in long chats and reduced background activity in inactive tabs.
- Improved startup and background loading to reduce flicker.
- Added individual website toggles and website-specific model preferences.
- Extended message queues and privacy controls to supported chats on the new websites.
- Bundled fonts locally instead of fetching them from Google Fonts.
- Added independent controls for hiding AI disclaimers and ChatGPT sponsored placements.
- Removed the token counter and bundled tokenizer to reduce package size.
